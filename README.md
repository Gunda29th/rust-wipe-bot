# 🧻 Rust Wipe Bot

A Discord bot for managing and tracking Rust server wipe schedules.

---

## ✨ Features

- 📅 Weekly wipe schedules
- 📅 Monthly wipe schedules
- 🌍 Timezone support
- ⏳ Live countdown to the next wipe
- 🔄 Shows the following wipe
- ⚙️ Server-specific settings
- 💾 Automatically saves configuration
- 🎯 Easy slash commands

---

## 📋 Commands

### `/setwipe`
Configure the server's wipe schedule.

### `/wipe`
Show the next wipe time and countdown.

### `/settings`
Display the current wipe configuration.

### `/help`
Show all available commands.

---

## 🚀 Installation

### 1. Install Python

Download Python 3.12 or newer:

https://www.python.org/downloads/

---

### 2. Download the Bot

Download this repository as a ZIP and extract it.

---

### 3. Install Dependencies

Open a terminal in the project folder and run:

```bash
pip install -r requirements.txt
```

---

### 4. Configure the Bot

Create a `.env` file using `.env.example`.

Example:

```env
DISCORD_TOKEN=YOUR_DISCORD_BOT_TOKEN
```

---

### 5. Start the Bot

```bash
py main.py
```
